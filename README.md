# Finance Analysis Reports using Excel

## 📌 Project Overview 

This project was created as part of my Data Analytics learning journey to strengthen my practical skills in Excel-based financial analysis, reporting, and data visualization.
The reports focus on Profit & Loss (P&L) analysis across different fiscal years, months, and markets.

## 📊 Reports

### 1. _[P&L Statment by Fiscal Year](https://github.com/Gavyamaharajan/Excel-Finance_Analysis/blob/main/P%26L%20by%20Fiscal%20Year.pdf)_
- Year-wise overview of financial performance 
- Comparison of key financial metrics across fiscal years

### 2. _[P&L Statement by Month](https://github.com/Gavyamaharajan/Excel-Finance_Analysis/blob/main/P%26L%20by%20Months.pdf)_
- Monthly breakdown of financial performance
- Identify sales and profitability trends throughout the year
  
### 3. _[P&L Statement by Market](https://github.com/Gavyamaharajan/Excel-Finance_Analysis/blob/main/P%26L%20by%20Market.pdf)_
- Market-wise sales contribution, margins, and profitability

## 🎯 Objective
This project transforms raw finance data into meaningful business insights using Excel.

The analysis aims to:

- Analyze financial performance across different periods and markets
- Identify high-performing and underperforming markets
- Present financial data in a structured and easy-to-understand format
- Build practical Excel-based reporting skills

Role of reports:

- To provide a consolidated view of financial performance
- To analyze the data from different perspectives, including Fiscal Year, Month, and Market
- Identify potential business expansion opportunities in promising countries
